# Calle 5 Taco Truck

A fast, responsive, dependency-free marketing site for Calle 5 Taco Truck.

## Preview locally

```bash
python3 -m http.server 4173
```

Then open <http://localhost:4173>.

## Updating content

- Events are in the `#events` section of `index.html`.
- Instagram and TikTok URLs are placeholders and can be replaced globally in `index.html`.
- The catering form uses semantic fields and stable `name` attributes, ready to connect to an email provider, CRM, or custom backend.
- CTA elements include tracking-friendly classes prefixed with `cta-`.
